# ep01 화면 구성

제목(표지): **같은 AI인데 남의 글만 사람 같은 이유, 딱 3줄 차이**
형식: 세로 1080×1920, 약 37초, 내레이션 초당 6.6음절, 자막 `punch`(1~2단어, 노란색 강조)

| # | 내레이션 | 화면 | 증거 / 메모 |
|---|---|---|---|
| 1 | AI한테 '글 써줘' 하는 순간, 그 글은 망했어요. | 채팅 입력창에 "글 써줘" 타이핑 → 엔터 순간 빨간 도장 **망함** | 0초부터 바로 시작 |
| 2 | 재료 없이 시키면, AI는 제일 평범한 문장을 쓰거든요. | 빈 재료 바구니 → 회색 문장들이 쏟아짐 | |
| 3 | 카페 홍보글이면, '따뜻한 공간, 특별한 커피.' 이런 거요. | **실제 AI 답변 화면**: "카페 홍보글 써줘" 결과 | ⚠️ 실제로 돌려서 나온 문장으로 교체할 것 |
| 4 | 바로 티 나죠. | 그 문장에 빨간 밑줄 + "AI 티" 스티커 | 짧게, 0.6초 |
| 5 | 그래서 딱 세 가지만 바꿔 볼게요. | 카드 3장(재료 세 줄 · 금지어 리스트 · 말투 복사)이 뒤집힌 채 등장 | 무엇을 배울지 미리 보여 줌 |
| 6 | 첫째, 재료 세 줄. | 카드 1 뒤집힘: **재료 세 줄** | 팁 이름을 크게 |
| 7 | 누가 읽는지, 왜 쓰는지, 내 경험 한 줄. | 체크리스트 3줄이 하나씩 채워짐 | |
| 8 | 같은 카페 글인데, 이것만 넣어도 이렇게 달라져요. | **전/후 나란히**: 왼쪽 "글 써줘" 결과, 오른쪽 재료 3줄 넣은 결과 | ⚠️ 핵심 증거. 실제 결과 캡처 사용 |
| 9 | 둘째, 금지어 리스트. | 카드 2 뒤집힘: **금지어 리스트** | |
| 10 | '물론이죠', '다양한'. 이런 말은 빼라고 하세요. | 단어들이 날아와 빨간 X로 지워짐 | |
| 11 | 그런데 아직 어색해요. | 결과 글이 살짝 흔들림, 물음표 | 리훅 |
| 12 | 진짜 사람 같아지는 건 세 번째예요. | 빨간 숫자 **03** 크게 (긴장감) | 가장 센 팁을 마지막에 |
| 13 | 셋째, 말투 복사. | 카드 3 뒤집힘: **말투 복사** | |
| 14 | 내가 쓴 글 두세 개를 주고, 이 말투로 쓰라고 하세요. | 내 글 2~3개가 AI 입력창으로 들어감 | |
| 15 | 이제 내가 쓴 글처럼 읽혀요. | 최종 결과 글. 처음(#3) 문장과 비교해 확 달라진 모습 | ⚠️ 실제 결과 사용. 처음과 대비 |
| 16 | 세 개 다 넣은 복붙 프롬프트, 금지어 서른 개까지. | 복붙 프롬프트 문서 미리보기(흐리게) + "금지어 30" 배지 | 내용은 다 안 보여 줌 |
| 17 | 댓글에 '복붙' 남기면 디엠으로 드려요. | 댓글창에 "복붙" 입력 → DM 알림 | 끝 화면 1~2초 유지 |

## 촬영/제작 전 준비

- [ ] DM으로 보낼 복붙 프롬프트 (재료 세 줄 + 금지어 30개 + 말투 복사 칸)
- [ ] 인스타그램 댓글 키워드 → DM 자동 발송 설정 ("복붙")
