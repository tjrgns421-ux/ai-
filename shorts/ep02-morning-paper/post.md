# ep02 업로드 패키지 — Morning Paper 블로거용 보완판

## 표지(커버) 제목 후보 (제목 공식: 이득 + 사건 + 의외성 + 숫자)

1. **블로그 글감, 매일 아침 신문으로 받는 법** ← 추천 (이득이 바로 보임, 과장 없음)
2. 아침마다 뉴스 뒤지는 블로거, 이 스킬 하나면 끝
3. 무료 깃허브 스킬에 한 단계 더 붙였더니, 글감이 알아서 와요
4. 글 67개 대신 신문 1장, 그리고 글감 3개 (⚠️ "67개"는 원본 영상의 숫자라 쓰지 않음)

커버 그림: 실제 "오늘의 블로그 글감" 면(`video/public/ep02/paper-ideas.png`) 위에
연두 띠 "+ 오늘의 블로그 글감", 오른쪽 아래 프프 ^_^.

## 캡션 (본문)

```
블로그 글감 찾으려고 아침마다 뉴스 뒤지고 있다면 👇

Morning Paper는 내가 보는 사이트·뉴스레터·유튜브를 모아
매일 아침 신문 한 장으로 만들어 주는 무료 오픈소스 스킬이에요.

근데 신문은 신문일 뿐, 뭘 쓸지는 또 골라야 하죠.
그래서 블로거용으로 한 단계를 더 붙였어요.

✔ 오늘 쓸 글감 3개
✔ 글감마다 제목 후보 3개 + 글 뼈대
✔ 근거 기사 링크 (출처 확인용)
✔ 컴퓨터를 꺼 둬도 매일 아침 6시에 실행

📩 댓글에 "글감" 남기면 복붙용 설치 프롬프트를 DM으로 보내 드려요.

원작: github.com/dmthepm/morning-paper (MIT, Devon Meadows)
영상 속 글감 면은 실제 뉴스로 직접 만들어 본 결과예요.
기사 내용은 그대로 옮기지 말고, 근거 링크로 확인한 뒤 내 관점으로 써 주세요.
```
