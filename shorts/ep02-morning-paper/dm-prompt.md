# DM 자료: Morning Paper 한국어 보완판 설치 프롬프트

> Morning Paper(`dmthepm/morning-paper`, MIT, Devon Meadows) 오픈소스 스킬을
> 한국에서 쓸 때 막히는 곳까지 미리 해결하도록 만든 설치 프롬프트입니다.
> 아래 상자 안의 내용을 통째로 복사해서 **Claude Code**에 붙여 넣으세요.

---

```text
Morning Paper(매일 아침 나만의 신문)를 이 컴퓨터에 설치하고, 한국어로 제대로
나오게 만들어 줘. 성공 기준은 "패키지 설치 완료"가 아니라 "한글이 깨지지 않은
신문 PDF가 내 화면에 열려 있는 것"이야. 아래 순서대로 끝까지 진행해 줘.

[1단계: 엔진 설치]
1. 최신 `morning-paper[pretty]`를 설치해. 가능하면
   `uv tool install --python 3.13 "morning-paper[pretty]"`를 쓰고,
   uv가 없으면 `pipx install --python 3.13 "morning-paper[pretty]"`를 써.
2. `morning-paper --version`이 PyPI 최신 버전과 같은지 확인해.
3. `morning-paper doctor --strict`를 실행하고, 지적하는 문제를 해결될 때까지 고쳐 줘.
   (Mac이면 인쇄용 라이브러리 `brew install pango gdk-pixbuf`가 필요할 수 있어.)
4. `morning-paper demo --open`으로 샘플 신문이 열리는지 확인해.

[2단계: 한글 폰트 문제 해결 — 기본 설정만으로는 한글이 깨지거나 어색해]
Morning Paper에 내장된 폰트는 영문 폰트뿐이라, 한글은 컴퓨터에 깔린 다른
폰트로 대신 표시돼. 한글 폰트가 없으면 네모로 깨지고, 있어도 중국어 폰트로
잡혀서 제목이 얇게 나올 수 있어.
1. 한글 폰트(Pretendard 또는 Noto Sans KR)를 설치해.
2. 설치만으로는 안 바뀌는 경우가 있어. 이 컴퓨터의 폰트 설정(fontconfig)에서
   한국어(lang=ko)와 sans-serif/serif의 우선 폰트로 그 한글 폰트를 지정하고
   폰트 캐시를 새로 고쳐 줘.
3. 확인: 아래 내용으로 test.md를 만들어 `morning-paper render test.md`로 PDF를
   만들고, PDF에 들어간 폰트 목록(예: pdffonts)을 확인해서 한글이 내가 설치한
   한글 폰트로 들어갔는지 검증해. 중국어 폰트(WenQuanYi 등)나 빈 네모가 보이면
   2번을 다시 해 줘.
   ---
   # 나의 아침 신문
   ## AI 툴 소식
   오늘 아침 주요 소식입니다. 영문 English와 숫자 123도 함께 확인합니다.
   ---
4. 단어와 조사 사이(예: "사례 / 가")에서 줄이 바뀌는지도 봐 줘. 그렇다면
   Morning Paper의 디자인 설정에서 한국어 줄바꿈(word-break: keep-all)을 적용할
   방법이 있는지 확인하고, 있으면 적용해 줘. 없으면 그렇다고만 알려 줘.

[3단계: 내 신문 만들기]
1. Claude Code 플러그인을 설치해:
   `/plugin marketplace add dmthepm/morning-paper` 그다음
   `/plugin install morning-paper@morning-paper`
2. "set up my morning paper"로 내 신문 편집국을 만들어 줘.
3. 내가 매일 보는 출처를 물어보고 SOURCES.md에 정리해 줘. 한국어 출처
   (예: 긱뉴스, AI타임스, 블로터)와 유튜브 채널도 넣을 수 있게 도와줘.
4. 뉴스레터를 메일로 받아 읽게 하고 싶다면: 내 원래 메일 비밀번호는 절대 쓰지
   말고, 앱 비밀번호와 신문 전용 주소(예: 내아이디+paper@gmail.com)를 쓰도록
   안내해 줘. 비밀번호나 키는 채팅창에 다시 출력하지 말고 설정 파일에만 저장해.

[4단계: 매일 아침 자동 실행]
1. 컴퓨터를 꺼도 돌게 하고 싶으면 Claude Code 루틴(/schedule)으로 매일 아침
   6시에 신문을 만들도록 걸어 줘. 클라우드에서 돌릴 때는 매번 새 환경에서
   시작하니까, 1단계 설치와 2단계 한글 폰트 설정이 실행할 때마다 다시
   적용되는지, 그리고 SOURCES.md의 사이트들에 접속이 허용돼 있는지 확인해 줘.
2. 클라우드 루틴을 쓸 수 없으면 `morning-paper routine install --time 06:00`
   (내 컴퓨터용 예약)으로 대신 걸어 줘. 이 경우엔 그 시간에 컴퓨터가 켜져
   있어야 한다고 알려 줘.
3. 마지막으로 지금 한 번 바로 실행해서 오늘 자 신문이 한글로 잘 나오는지
   보여 줘.

끝나면 실제로 성공한 명령어, 설치된 버전, 신문 PDF 경로, 한글 폰트 확인 결과를
정리해서 보여 줘.
```

## 이 프롬프트가 원래 설명과 다른 점 (보완한 곳)

| 보완 | 이유 |
|---|---|
| 한글 폰트 설치 **+ 우선순위 지정 + PDF 폰트 검증** | 내장 폰트가 영문뿐이라 한글이 대체 폰트로 표시됨. 실험 결과 **폰트를 설치만 해서는 바뀌지 않았고**, 우선순위를 지정해야 한글 폰트로 바뀌었음 |
| 한국어 줄바꿈 확인 | 단어와 조사 사이에서 줄이 바뀌는 현상을 실험에서 확인 |
| 메일 연결은 앱 비밀번호 + 전용 주소 | 원래 비밀번호 노출 위험 방지 |
| 클라우드 루틴의 설치·폰트·네트워크 확인 | 클라우드는 매번 새 환경이라, 설치와 폰트 설정이 매번 적용돼야 하고 출처 사이트 접속이 허용돼야 함 |
| 클라우드 루틴이 안 되면 로컬 예약 + "컴퓨터 켜 둬야 함" 안내 | 대안과 조건을 정확히 알려 줌 |

## 검증 상태 (2026-11-17, 이 저장소의 클라우드 세션에서)

- ✅ `morning-paper[pretty]` 0.8.13 설치 (PyPI, Python 3.13)
- ✅ 기본 상태: 한글이 중국어 폰트(WenQuanYi)로 대체되고 제목이 얇게 나옴
- ✅ 한글 폰트(Pretendard) 설치만으로는 변화 없음
- ✅ fontconfig에서 우선순위 지정 후: 한글이 Pretendard로 들어가고 제목이 굵게 나옴
- ⚠️ 단어·조사 사이 줄바꿈: 아직 해결 방법 미확인
- ⚠️ `doctor --strict`, 플러그인 설치, 클라우드 루틴: 이 세션에서는 아직 실행하지 않음
