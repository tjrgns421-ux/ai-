# DM 자료: Morning Paper 블로거용 보완판 설치 프롬프트

> Morning Paper(`dmthepm/morning-paper`, MIT, Devon Meadows)는 매일 아침
> 내 출처로 신문 한 장을 만들어 주는 오픈소스 스킬입니다. 원래 기능은
> "읽을 신문"까지라서, **블로그에 쓸 글감을 골라 주는 단계**를 더했습니다.
> 아래 상자 안의 내용을 통째로 복사해서 **Claude Code**에 붙여 넣으세요.

---

```text
Morning Paper(매일 아침 나만의 신문)를 설치하고, 블로거용으로 "오늘의 블로그
글감" 면을 더해 줘. 성공 기준은 "설치 완료"가 아니라 "글감 면이 들어간 오늘 자
신문 PDF가 내 화면에 열려 있는 것"이야. 아래 순서대로 끝까지 진행해 줘.

[1단계: 설치]
1. 최신 `morning-paper[pretty]`를 설치해. 가능하면
   `uv tool install --python 3.13 "morning-paper[pretty]"`를 쓰고,
   uv가 없으면 `pipx install --python 3.13 "morning-paper[pretty]"`를 써.
2. `morning-paper doctor --strict`가 지적하는 문제를 해결될 때까지 고쳐 줘.
   (Mac이면 `brew install pango gdk-pixbuf`가 필요할 수 있어.)
3. `morning-paper demo --open`으로 샘플 신문이 열리는지 확인해.
4. 확인: 한글로 된 짧은 문서를 `morning-paper render`로 찍어서 한글이 네모로
   깨지지 않는지 봐 줘. 깨지면 한글 폰트(Pretendard 또는 Noto Sans KR)를
   설치하고, 폰트 설정에서 한국어 우선 폰트로 지정해 줘.

[2단계: 내 신문 만들기]
1. 플러그인 설치: `/plugin marketplace add dmthepm/morning-paper` 그다음
   `/plugin install morning-paper@morning-paper`
2. "set up my morning paper"로 내 신문 편집국을 만들어 줘.
3. 내가 매일 보는 출처를 물어보고 SOURCES.md에 정리해 줘. 한국어 출처
   (예: 긱뉴스, AI타임스, 블로터)와 유튜브 채널도 넣을 수 있게 도와줘.
4. 뉴스레터를 메일로 받아 읽게 하고 싶다면: 내 원래 메일 비밀번호는 절대 쓰지
   말고, 앱 비밀번호와 신문 전용 주소(예: 내아이디+paper@gmail.com)를 쓰도록
   안내해 줘. 비밀번호나 키는 채팅창에 다시 출력하지 말고 설정 파일에만 저장해.

[3단계: "오늘의 블로그 글감" 면 추가 — 이 프롬프트의 핵심]
1. 먼저 나에게 물어봐: 내 블로그 주제(예: AI 툴, 육아, 재테크), 주로 쓰는
   글 형식(정보 정리, 후기, 비교 등), 독자.
2. 내 편집국 설정 파일(EDITORIAL.md 등)에 아래 규칙을 기록해서, 매일 신문의
   마지막 면에 "오늘의 블로그 글감"이 항상 들어가게 해 줘.
   - 오늘 신문 기사 중 내 블로그 주제에 맞는 글감 3개를 고른다.
   - 글감마다: ① 왜 지금 쓸 만한지 한 줄 ② 제목 후보 3개
     ③ 근거 기사 제목과 링크(출처 명시) ④ 글의 뼈대(소제목 3~4개).
   - 기사 문장을 그대로 옮기지 않는다. 글감은 내 관점으로 쓸 수 있게 제안만
     하고, 사실은 근거 기사로 확인할 수 있게 링크를 단다.
   - 주제에 맞는 글감이 3개가 안 되면 억지로 채우지 말고 있는 만큼만 쓴다.
3. 오늘 자 신문을 한 번 만들어서 글감 면이 제대로 들어갔는지 보여 줘.

[4단계: 매일 아침 자동 실행]
1. 컴퓨터를 꺼도 돌게 하고 싶으면 Claude Code 루틴(/schedule)으로 매일 아침
   6시에 신문을 만들도록 걸어 줘. 클라우드는 매번 새 환경에서 시작하니까,
   1단계 설치가 실행할 때마다 다시 되는지, 그리고 SOURCES.md의 사이트들에
   접속이 허용돼 있는지 확인해 줘. 막혀 있으면 어떤 주소를 허용해야 하는지
   알려 줘.
2. 클라우드 루틴을 쓸 수 없으면 `morning-paper routine install --time 06:00`
   (내 컴퓨터용 예약)으로 대신 걸어 줘. 이 경우엔 그 시간에 컴퓨터가 켜져
   있어야 한다고 알려 줘.

끝나면 성공한 명령어, 설치된 버전, 신문 PDF 경로, 그리고 오늘의 글감 3개를
정리해서 보여 줘.
```

## 원래 스킬과 다른 점 (보완한 곳)

| 보완 | 이유 |
|---|---|
| **"오늘의 블로그 글감" 면** (글감 3개, 제목 후보, 근거 링크, 글 뼈대) | 원래 스킬은 읽을 신문까지. 플러그인의 `writing` 스킬은 신문 문장 교정용이라 글감 기능이 없음 (저장소에서 확인) |
| 내 블로그 주제·형식·독자를 먼저 물어봄 | 글감이 내 블로그에 맞게 골라지도록 |
| 기사 문장 그대로 옮기지 않기, 출처 링크 | 저작권과 사실 확인 |
| 클라우드 루틴의 설치·접속 확인, 안 되면 로컬 예약 + "컴퓨터 켜 둬야 함" | 클라우드는 매번 새 환경이라 설치와 사이트 접속이 매번 필요 |
| 메일 연결은 앱 비밀번호 + 전용 주소 | 원래 비밀번호 노출 방지 |
| 한글 깨짐 확인 한 줄 | 한글 폰트가 없는 서버에서는 한글이 네모로 깨지는 것을 확인함 |

## 검증 상태 (2026-11-17, 클라우드 세션)

- ✅ `morning-paper[pretty]` 0.8.13 설치, `render` 동작
- ✅ 플러그인 스킬 3종(setup, edition, writing) 내용 확인: 글감 기능 없음
- ✅ 한글 폰트 없는 환경에서 한글이 네모로 깨짐 / 우선순위 지정으로 해결
- ⚠️ 3단계(글감 면)를 실제 뉴스로 만든 결과: 아직 (뉴스 사이트 접속 필요)
- ⚠️ `doctor --strict`, 플러그인 설치, 클라우드 루틴: 아직 실행 안 함
